# Licensing

Longtable is free software, in layers. This file says exactly which
license covers which part of the project.

## Code — AGPLv3

All source code in this repository — the app (`src/`), the hub (`hub/`),
the AppView (`appview/`), signaling, examples, and tooling — is licensed
under the **GNU Affero General Public License, version 3** (see
[`LICENSE`](LICENSE)).

AGPLv3 was chosen deliberately: anyone may use, study, modify, and
redistribute the code, including commercially — but anyone who runs a
modified version as a network service must offer their users that
version's source. A hosted fork cannot quietly close itself off and
capture the network; improvements flow back to everyone. That is the
project's anti-centralization rule expressed as a license.

## Protocol and lexicons — CC0 1.0

The `kitchen.longtable.*` lexicon schemas in [`lexicons/`](lexicons/) and
the protocol specification in [`docs/public-protocol.md`](docs/public-protocol.md)
are dedicated to the public domain under **CC0 1.0 Universal** (see
[`LICENSE-CC0.txt`](LICENSE-CC0.txt)).

Anyone may implement the Longtable protocol — a client, a hub, an
AppView — in their own software, under their own license, without
asking. Interoperability is not something we license back to you.

## Documentation — CC0 1.0

The developer documentation in [`docs/`](docs/) is likewise CC0 1.0, so
it can be copied, translated, and adapted without restriction.

## Contributions

Contributions are accepted under the Developer Certificate of Origin
(DCO) — see [`CONTRIBUTING.md`](CONTRIBUTING.md). There is no copyright
assignment and no CLA.

## The name

"Longtable" is covered by a short trademark policy — see
[`TRADEMARKS.md`](TRADEMARKS.md). The license grants rights in the
code, not in the name.
