# The Longtable name

The software in this repository is free under the licenses in
[`LICENSING.md`](LICENSING.md) — fork it, modify it, run it, share it.
The **name** is different, for one practical reason: people should be
able to tell whether the app in front of them is the one whose code
they can inspect here.

- Unmodified builds of this software may call themselves **Longtable**.
- A **modified** version must use a different name (a "based on
  Longtable" credit is welcome, and accurate attribution is always
  fine).
- Hubs, clients, and services that interoperate with the Longtable
  protocol may say so ("works with Longtable", "a Longtable hub"), but
  may not present themselves as the Longtable project itself.

That's all. If a use isn't covered here and you're unsure, ask — the
intent is to prevent confusion, not to control what anyone builds.
